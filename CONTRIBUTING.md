# Contributing

Use Python 3.13 and follow the setup in README.md. Keep all analysis in the one notebook and reusable logic in `src/olist_analytics/`. Preserve original data and record changes to features, splits or model settings.

Before proposing a change, run the notebook and relevant checks listed in the README. Explain the business or analytical reason, report measured results, and include any new limitations. Do not tune against the already inspected test period and call it an untouched evaluation. Never include credentials or private customer information in a commit or issue.

The repository includes historical academic results. Contributions must not claim validated business ROI, reliable demand forecasts or protected-group fairness without supporting evidence.
